# Facturas de proveedor

Sólo administradores pueden listar, crear, editar vencimiento/notas/adjunto o anular facturas. El total, pagado y saldo que se visualizan son siempre los devueltos por la API.

Al asociar una OC, sólo se ofrecen órdenes confirmadas o cerradas del proveedor seleccionado. Si la API exige confirmación por diferencia, se debe tildar la confirmación y explicar el motivo antes de reenviar.
