# Combos — operación

Un combo agrupa productos y cantidades por un precio único. En el carrito, el descuento de cada set completo es **precio regular − precio combo**; las unidades se consumen una sola vez y el beneficio puede combinarse con una promoción.

Para publicarlo, la composición debe sumar al menos dos unidades, todos los productos deben estar activos y tener precio vigente, y el precio combo debe ser mayor a cero y estrictamente menor al regular. La vigencia es opcional y el orden menor aparece primero.

La tienda oculta combos inactivos, fuera de vigencia, sin precio completo o cuyo ahorro sea cero o negativo. La imagen es opcional y puede cargarse después de crear el combo.
